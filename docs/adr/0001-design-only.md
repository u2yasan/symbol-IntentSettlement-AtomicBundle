# ADR-0001: 仕様詳細化と責務を記した雛形を先行する

状態: 今回の作業方針として採用 / 2026-10-26

依頼は「詳細実装はまだ、仕様書をもっと詳しくする」である。既存`codex/`には実装・ネットワーク検証まで進める指示があるが、今回はその実装段階を開始しない。

各ディレクトリに責務、入力、出力、予定ファイル、受入条件を記す。APIが確認できていないC++、CMake、SDKコマンドを仮実装しない。未割当の数値や鍵・接続先は`null`とし、起動可能な設定に見せない。

IntentSettlementとAtomicBundleは独立した比較案として設計する。将来の実装も別worktree・別genesis・別実行データとする。今回このフォルダ内に両案の文書が存在することは、両プラグインの同時導入を決定したことを意味しない。

この判断は実装禁止の恒久ルールではない。ユーザーが実装を依頼した段階でM0へ進める。署名、番号、fee、native処理順などの未確認事項は[判断一覧](../decisions.md)の完了条件を満たすまで未確定として扱う。
